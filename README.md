# Word Scramble Game 

Word Scramble Game is a web word puzzle game built BY ME.
In this game....players are given a scrambled version of a word and must correctly guess the original word before the timer runs out.
The game includes multiple difficulty levels...score tracking, and both challenging and fun.


# Features

- Random scrambled words are generated every round for unique FUN !!
- Theres multiple categories according to your interest 
- also theres diffuclty mode so you dont think yourself god after solving easy one! hahaaha
- Countdown timer also has been added to make it spicy
- In total 3 lives are given ( each of 15 second)
- Score tracking is given 
- Best score means player’s highest score.
- Hint feature helps you by revealing the starting letter
- Restart game allows quick replay after getting fumbled !!!
- Game over =  stops the game after all lives are lost.

# How To Play

1. Select a category and difficulty mode.
2. A scrambled word will appear on the screen.
3. Type the correct word into the input field.
4. Click “Check Answer” 
5. If your answer is correct, your score increases...
6. Wrong answers means -1 live
7. also If the timer reaches zero, one life is lost.
8. Use the restart button to play again.
